# Xəritəxana

Xəritəxana ölkələri göstəricilərə görə rəngləyən interaktiv dünya atlasıdır. Əhali, adambaşına ÜDM, orta ömür, internetdən istifadə və meşə örtüyü arasında keçid etmək olur. Xəritədə böyütmə, sürüşdürmə, axtarış və üzərinə gətirəndə qısa məlumat var. Ölkəni seçəndə yan paneldə sıra, müqayisə və bütün göstəricilər açılır. Bütün mətn azərbaycan dilindədir.

## İşə salmaq

```bash
npm install
npm run dev
```

Tətbiq [http://localhost:8080](http://localhost:8080) ünvanında açılır.

## Yığmaq

```bash
npm run build
npm run preview
```
